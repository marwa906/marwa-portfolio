# Marwa Portfolio

A polished, responsive personal portfolio for **Marwa Gharib Alsayed Mohamed**.

## Built with

- Semantic HTML5
- Modern CSS with responsive layouts
- Lightweight JavaScript scroll-reveal animations
- Google Fonts: Inter and Space Mono

## Run locally

Open `index.html` in a browser, or use any static server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deploy on GitHub Pages

1. Open the repository **Settings**.
2. Select **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select `main` and `/ (root)`, then save.

The profile photo currently uses the GitHub avatar URL for `marwa906`, so it stays synchronized with the current GitHub profile image.
